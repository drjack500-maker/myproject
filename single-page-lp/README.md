### そのほかの仕上げ

- **予約ボタンの文字色を白 → 紺に変更**。金色の背景に白文字はコントラスト比 2.8:1 で読みにくかったため（紺文字で 5.1:1）。スマホ下部の追従バーと比較表の見出しも同様
- スマホで見出しが1〜2文字だけ次の行に送られないように改行位置を調整（「ありま／せんか」「選べま／す」「立ち会いま／す。」「確認す／る」など）
- 構造化データの診療時間を、昼休みを含む実際の時間（9:30〜12:30／14:30〜19:00）に修正
- 横スクロールする比較表の枠を読み上げソフトで案内できるようにし、表の左上の空欄見出しに読み上げ用の名前を追加
- iPhone の横向き表示で、ノッチ部分に文字がかからないように余白を調整
- 画像すべてに縦横サイズを指定（読み込み中のガタつき防止）、ファーストビュー以外は遅延読み込み
