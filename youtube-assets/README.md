# YouTube 動画に入れる素材（栄院）

テレビで見ている人（このチャンネルの再生の23.5%・約5,300人）は、説明欄や固定コメントのリンクを押せません。動画の画面に **QRコードと電話番号** を出すための素材です（根拠：[計画書9章](../docs/youtube-acquisition-plan.md#9-youtube-studio-のデータ2026年10月5日に書き出し)）。

| ファイル | 大きさ | 使う場所 |
|---|---|---|
| [`endscreen-1920x1080.png`](endscreen-1920x1080.png) | 1920×1080 | **動画の最後の20秒**の背景 |
| [`qr-overlay-520x660.png`](qr-overlay-520x660.png) | 520×660（背景透明） | **冒頭60秒以内**と**2分前後**の案内のときに、画面の隅に重ねる |
| [`lower-third-1920x220.png`](lower-third-1920x220.png) | 1920×220（背景透明） | **最初の自己紹介**と案内のときに、画面の下に重ねる |

QRコードを読み取ると、LINE の友だち追加ページ（[`qr-target.txt`](qr-target.txt) のURL）が開きます。テレビの画面を1/4に縮小した状態でも読み取れることを確認しています（`tests/youtube-assets.test.js`）。

## 動画編集での使い方

平均視聴は3〜5分なので、**最後だけでなく冒頭と2分前後にも**出します。院長が話す案内の台本は [`docs/youtube-templates.md` の4章](../docs/youtube-templates.md#4-動画内の案内次回の撮影から) にあります。

| タイミング | 出すもの | 長さ | 置き方 |
|---|---|---|---|
| 0:05〜0:20（「名古屋・栄の北村です」の自己紹介） | 電話番号の帯 | 約15秒 | 画面の下・左寄せ（素材のまま） |
| 冒頭60秒以内の案内 | 重ねるQRコード＋電話番号の帯 | 10〜15秒 | QRコードは右下か右上。院長の顔にかからない位置に、等倍〜80%で |
| 2分前後の案内 | 重ねるQRコード＋電話番号の帯 | 10〜15秒 | 同上 |
| 最後の20秒 | 終了画面 | 20秒 | 画面いっぱい。院長が案内を読み上げる（台本の「最後の20秒」） |

- 費用の話をする場面では、別に「自由診療（公的医療保険の適用外）・標準的な費用・主なリスク」のテロップを入れてください（医療広告ガイドライン。計画書5章）
- QRコードを動画の中で動かしたり、小さくしすぎたりしないでください（重ねるQRコードは、1080pの画面で幅400px以上が目安）

## YouTube Studio の終了画面の置き方

終了画面の画像の右側にある点線の枠に合わせて、YouTube Studio の「終了画面」で要素を置きます。

1. 「動画」→ 上の枠（次の動画）に合わせる。どの動画を置くかは [`docs/youtube-video-texts.md`](../docs/youtube-video-texts.md#一覧終了画面関連動画) の一覧のとおり
2. 「再生リスト」→ 下の枠に合わせる
3. 「登録」ボタンを使う場合は、右下の空いた場所に。**左側（QRコード・電話番号）には何も重ねない**でください

## すでに公開している動画について

公開済みの動画に、あとから画像を重ねることはできません（再アップロードすると再生回数がゼロに戻ります）。公開済みの動画は「固定コメント・説明欄・終了画面」で対応し（[`docs/youtube-video-texts.md`](../docs/youtube-video-texts.md)）、この素材は**次に撮影・編集する動画から**使ってください。

## 作り直すとき

```bash
npm run build:youtube-assets                                    # 文言やデザインを変えたとき（tools/build-youtube-assets.js を編集）
npm run build:youtube-assets -- --line=https://s.lmes.jp/...    # LINE の経路を変えるとき
npm run test:e2e                                                # QRコードが読み取れるか確認
```

L-Message で「栄院youtube動画内QR」の流入経路を作ると、動画の画面から追加した人を、説明欄から追加した人と分けて数えられます。経路を作ったら、上の `--line=` でそのURLに作り直してください。
