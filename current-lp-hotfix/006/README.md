**掲載をやめたもの（HTMLのコメント・非表示として残しているので、戻すこともできます）**
- 「当院の治療でここまで変わります！」の **術前・術後写真4組**（セクションごと非表示）
- オールオンフォーの説明内の **術前・術後写真**
- 患者さまの声（手書きの体験談4件）

術前・術後写真は、各症例の「治療内容・費用・治療期間・リスク」を同じ場所に書けば掲載できます。新しいLP（`lp-006/`）では、この4組を症例セクションにセットしてあり、記入するだけで表示できます。

**追加したもの**

- 治療に伴う主なリスク・副作用（料金の注記の下）

**誤字・文字化け**
- 約30分**$301C**3時間 → 約30分〜3時間
- インプラント生入 → 埋入／ご都合に会わせて → 合わせて／治療期間を大幅に縮小 → 短縮／改善することができため → できるため

表示の確認：本番の画像・CSSを使ってスマホ幅（390px）で表示し、横スクロールが出ないこと、LINEバナーが今までどおりの大きさで表示されることを確認済みです。

## 差し替えの手順

1. サーバー上の今の `all_on_4_006/index.html` を **バックアップ**（別名で保存）
2. このフォルダの `index.html` を、同じ場所にアップロードして上書き
3. スマホで表示し、次の点を確認
   - 「当院の治療でここまで変わります！」と「患者さまの声」が表示されていない
   - 料金の下に「税込 1,925,000円」とリスク・副作用が表示されている
   - 予約ボタン・電話ボタン・LINEボタンが今までどおり動く

> 今のLPのHTMLが 10月6日以降に更新されている場合は、差し替えると更新分が消えます。その場合は、最新のHTMLを `index.original.html` として保存し、`npm run build:hotfix` で作り直してください（修正箇所が見つからない場合は、どこかを表示して止まります）。

## この応急処置では直せないもの

- **表示の重さ（最初に約10MB）**…画像の作り直し・Webフォント・動画の読み込み方の変更が必要です（新LPでは約285KB）
- **最初の画面に予約ボタンがない**…メイン画像が1枚の画像のため、作り直しが必要です
- **予約システム（Apotool）の注意書き**…Apotool の管理画面で、医院メッセージを短くし、別医院の検索案内を削除してください
- **理事長メッセージが矯正歯科の内容**（「美しい歯並びを目指しましょう」）…文章の差し替えには理事長の確認が必要です
- ページの長さ・構成、Meta への予約完了の計測…新しいLP（`lp-006/`）で対応しています（[診断と改善版の説明](../../docs/lp-006-review.md)）
