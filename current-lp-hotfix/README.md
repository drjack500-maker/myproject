## 差し替えの手順

1. サーバー上の今の `all_on_4_004/index.html` を **バックアップ**（別名で保存）
2. このフォルダの `index.html` を、同じ場所にアップロードして上書き
3. スマホで表示し、次の点を確認
   - 「患者さまの声」が表示されていない
   - 料金の下に「税込 1,925,000円」とリスク・副作用が表示されている
   - 予約ボタン・電話ボタン・LINEボタンが今までどおり動く

> 今のLPのHTMLが 9月30日以降に更新されている場合は、差し替えると更新分が消えます。その場合は、最新のHTMLを `index.original.html` として保存し、`npm run build:hotfix` で作り直してください（修正箇所が見つからない場合は、どこかを表示して止まります）。

## この応急処置では直せないもの

- **最初の画面の画像**（「インプラント治療／たった1日でしっかり噛める歯に」）…画像の中の文字のため、画像の作り直しが必要です
- **予約システム（Apotool）の注意書き**…Apotool の管理画面で、医院メッセージを短くし、別医院の検索案内を削除してください
- **実績の数字**（2023年の集計）…最新年の数字が必要です
- ページの長さ・構成…新しいLP（`lp/`）で対応しています
