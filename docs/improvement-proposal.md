## 1. 結論：優先度の高い10施策

| # | 施策 | 狙い | 工数 |
|---|---|---|---|
| 1 | **ファーストビュー（FV）で「当日に固定式の歯」「価格」「名古屋駅2分」「予約ボタン」を3秒で伝える** | 直帰を減らす。スマホの最初の画面に予約ボタンを入れる | 小 |

## 2. 現LPチェックリスト

現LPを見ながら、当てはまらない項目（＝改善余地）を拾ってください。

### ファーストビュー
- [ ] スマホの最初の画面（375×667程度）に**予約ボタンが見えている**
- [ ] 見出しで**ユーザーが得られる結果**（当日に固定式の歯／入れ歯のストレス軽減）を言い切っている（医院名や治療名だけになっていない）
- [ ] **価格（税込）と月額**がFVに出ている。あわせて「手術費用のみ／諸費用別途」など条件を併記している
- [ ] 「名古屋駅 徒歩2分」「静脈内鎮静法」「分割払い」など**選ぶ理由**が一目で分かる
- [ ] ヒーロー画像が「イメージ写真」だけで終わらず、院長や院内など**実在する情報**を見せている

### 内容
- [ ] 入れ歯・1本ずつのインプラントとの**違いが比較で分かる**
- [ ] 痛み・年齢・持病・骨の量への**回答がFAQより前**に出てくる
- [ ] 費用の**内訳（含まれるもの／別途のもの）**と、総額の説明タイミングを明記している
- [ ] 医療費控除について**具体的な金額の目安**を出している
- [ ] 治療の流れに**期間・回数の目安**がある
- [ ] 院長の**顔写真・経歴・メッセージ**がある
- [ ] 症例写真に**治療内容・費用・期間・リスク**が併記されている

### 行動（CTA・フォーム）
- [ ] 各セクションの切れ目にCTAがあり、スマホでは**追従ボタン**がある
- [ ] 電話番号が**タップで発信**でき、受付時間が併記されている
- [ ] フォームの**必須項目が3つ以内**（氏名・電話・希望日時）
- [ ] 希望日を**カレンダー入力ではなくタップで選べる**
- [ ] 「相談だけでもOK」「無理な勧誘はしない」「家族同伴歓迎」がボタン付近にある
- [ ] 送信後に**サンクスページ**へ遷移し、そこでCVを計測している

### 表示速度・技術
- [ ] モバイルのLCPが2.5秒以内（PageSpeed Insightsで確認）
- [ ] 大きな画像はWebP/AVIF化し、`width` / `height` 指定と遅延読み込みをしている
- [ ] 広告のパラメータ（gclid・utm）がフォーム送信時に保存されている

### 医療広告ガイドライン
- [ ] 「No.1」「地域一番」「成功率99%」「痛くない」「絶対」など、**比較優良・誇大と取られる表現がない**
- [ ] **患者の体験談（治療内容・効果に関する口コミ）を載せていない**
- [ ] 「今だけ半額」「先着○名モニター価格」など**費用を強調した表現がない**
- [ ] **自由診療の内容・費用・リスク・副作用**、問い合わせ先が明記されている

> 参考：同法人サイトには「成功率99％」「安いAll-on-4」といった見出しのページがあります。LPにも同様の表現がある場合は、根拠（集計期間・対象・定義）を示せない限り削除し、「費用」「分割」などの事実表現へ言い換えることを推奨します。

### 共通の工夫
- **大きめの文字（17〜18px）と「文字拡大」ボタン**（シニア層向け。設定はブラウザに保存）
- **スマホ下部の追従バー**（電話／LINE／予約）。FVを過ぎたら表示し、フォーム付近では隠す
- **広告キーワード別の見出し出し分け**（`?v=denture|price|bone|fear`、または `utm_term` から自動判定）
- **軽量化**：画像を使わずSVGで作図。外部ライブラリなし。JSは1ファイル
- **アクセシビリティ**：見出し構造、フォームのラベル、エラーの読み上げ、動きを減らす設定への対応

## 4. 医療広告ガイドライン対応

医療機関のウェブサイト（LPを含む）は医療法上の「広告」として規制されます。**違反は広告審査落ち（Google広告の配信停止）や行政指導につながり、CV以前に集客が止まります。**

### 言い換え例

| 避けたい表現 | 理由 | 言い換え例 |
|---|---|---|
| 痛くないオールオン4 | 誇大 | 痛みに配慮した静脈内鎮静法に対応 |
| 成功率99% | 根拠が示せない場合は誇大 | （根拠がなければ削除）／CT・デジタルガイドによる計画的な手術 |
| 名古屋No.1／症例数トップクラス | 比較優良 | 名古屋駅から徒歩2分（事実） |
| 1日で歯が入る | 誤認のおそれ（最終的な歯ではない） | 手術当日に**固定式の仮歯**を装着（※条件を併記） |
| 絶対に外れない | 断定 | 取り外し式の入れ歯と違い、固定式 |
| 今だけモニター価格○%OFF | 費用の強調 | 片あご1,925,000円（税込）／最大120回分割 |
| 患者様の声「もう何でも食べられます！」 | 体験談の掲載 | 掲載しない（口コミはGoogleビジネスプロフィールなど医院外で） |

### 必ず載せるもの（本LPでは対応済み）
- 自由診療であること、**標準的な費用**、治療期間・回数の目安
- **主なリスク・副作用**
- 医療機関名・所在地・電話番号（問い合わせ先）
- 術前・術後写真を載せる場合は、**同じ場所に治療内容・費用・期間・リスク**を併記

> 限定解除（ウェブサイトで通常は広告できない事項を載せられる条件）の扱いは、広告からの流入ページかどうかなどで判断が分かれる場合があります。症例写真などを掲載する前に、最新の厚生労働省「医療広告ガイドライン」とQ&Aを確認し、迷う場合は保健所や専門家に相談してください。

## 5. 計測設計

### 送信されるイベント（`dataLayer`）

| イベント | タイミング | 主なパラメータ |
|---|---|---|
| `lp_view` | 表示時 | `lp_variant`（見出しのパターン） |
| `section_view` | 各セクションが30%見えたとき | `section` |
| `cta_click` / `tel_click` / `line_click` | ボタン・電話・LINEのタップ | `cta`（どのボタンか） |
| `worry_check` | お悩みチェックをタップ | `worry`, `count` |
| `tax_sim_use` | 医療費控除シミュレーターを使用 | — |
| `faq_open` | FAQを開いた | `question` |
| `form_start` / `form_step` / `form_error` | フォームの操作 | `step` |
| `form_submit` | 送信成功 | `lp_variant`, `who`, `concerns`, `age` |
| `reservation_complete` | サンクスページ表示（**主要CV**） | — |

### Google広告での使い方
1. **主要CV**：`reservation_complete`（サンクスページ）。**補助CV**：`tel_click`（可能ならGoogle転送電話番号で「通話が60秒以上」を計測）
2. **フォームの隠し項目で `gclid` を保存** → 来院・契約の結果を**オフラインコンバージョンとしてインポート**。これで「予約は取れるが成約しない」キーワードに予算が流れるのを防げます
3. `lp_variant` 別・`concerns` 別にCVRと成約率を比較し、見出しと広告文を改善

### 見るべき指標（KPIツリー）
```
広告クリック数
  × LPの予約率（Web＋電話）      ← このLPで改善
  × 来院率（無断キャンセルしない）← 電話確認・前日リマインド
  × 成約率（治療を決める）        ← カウンセリング・見積もり後のフォロー
  = 成約数 → 成約単価（広告費 ÷ 成約数）で判断
```

## 6. A/Bテストの順番

1回に1つずつ変えて比較します。目安として**各パターンで予約が数十件**たまるか、**2〜4週間**回してから判断してください（件数が少ない段階での判断は偶然に左右されます）。

| 順 | テスト内容 | 仮説 |
|---|---|---|
| 1 | FV見出し：「当日に固定式の歯」vs「入れ歯を外さない毎日」vs 価格訴求 | 検索キーワード別に最も響く訴求が違う |
| 2 | FVの価格表示：総額＋月額 vs 月額を大きく | 月額を大きくすると心理的なハードルが下がる（総額と条件は必ず併記） |
| 3 | 予約ボタンの文言：「無料カウンセリングを予約」vs「オールオン4ができるか相談する」 | 「自分が対象か」を知りたい層には後者 |
| 4 | フォーム：3ステップ vs 1ページ | ステップ形式の方が完了率が高い |
| 5 | 追従バー：電話を大きく vs Web予約を大きく | 60代以上は電話の方が強い可能性 |
| 6 | お悩みチェックの有無 | 自分ごと化が予約率を押し上げる |

## 7. LPの外でできる改善（成約まで）

- **問い合わせへの即時対応**：Web予約には当日中（できれば数時間以内）に電話。つながらなければSMSで連絡
- **前日リマインド**（電話またはSMS）で無断キャンセルを防ぐ
- **家族が同伴しやすい枠**：土日祝が休診のため、平日夕方の枠やオンライン相談を用意すると、働く家族の同伴が増えます
- **持ち帰り資料**：ご家族に説明するための見積もり・治療計画の資料を渡す
- **保証制度があれば明記**：インプラント保証などは強い安心材料です（条件も併記）
- **口コミはLPに載せず**、Googleビジネスプロフィールで集める・返信する
