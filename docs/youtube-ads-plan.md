## 0. 結論

- **今の法人の YouTube 広告は、「再生回数を安く集める」設定のまま動いていて、LINE 登録につながっていません**（9日間で視聴26,375回・クリック8件・登録の計測なし）。計測と目的をそろえるまでは、予算を増やさないでください
- 栄院では、**名古屋近郊の55歳以上とご家族**に、**検討している人が長く見ている解説動画**を届け、**YouTube をご覧の方向けページと LINE** で受ける広告を、新しく小さく始めます
- 予算は**月約4.5万円**から。比べる基準は、栄院の Google 検索広告の**相談1件あたり約28万円**（2026年7〜9月：842,032円で3件）です。相談が1件でも出れば、検索広告より効率が良いことになります
- 始める前に、**計測（ページの公開・コンバージョン・LINE の経路）を先に整えます**。計測がないまま始めると、今の法人の広告と同じく「良いのか悪いのか分からない」状態になります

## 2. 法人の YouTube 広告の見直し

9月3日の依頼文（目的と設定のずれ、目標広告視聴単価1,000円の設定、クリックの少なさ、計測）は、どれも正しい指摘です。YouTube Studio のデータから、次の2点を追加で伝えてください。

1. **この広告の視聴は、栄院のチャンネルの再生に入っていません**（チャンネルのトラフィックソースに「YouTube 広告」は0回）。広告用に作った別の動画（47秒前後の横型）が使われていて、**院長の北村が出ている動画や、チャンネルへの信頼にはつながっていません**
2. **1回1.1円という安さは、見る気のない人にも広く流れている可能性が高い数字です**。次の内訳を出してもらい、名古屋近郊の55歳以上に届いているかを確認してください
   - 地域（「所在地」だけを対象にしているか。「関心のある地域」まで含めると全国に配信されます）
   - 年齢
   - 配信面（インストリーム・インフィード・ショート）
   - 視聴率と、動画の再生率（25%・50%・75%・100%）

**判断**：LINE 登録の計測（広告専用の L-Message 経路）と、配信の目的をそろえるまでは、**日予算を下げて様子を見る**ことをおすすめします。予算は、下の栄院の広告のテストに回せます。

## 3. 栄院の YouTube 広告

### 始める前にやること（チェックリスト）

- [ ] **YouTube をご覧の方向けページを公開**（`youtube-lp/`。予約フォームの受け皿 `formEndpoint` を設定。手順は [README](../README.md#youtube-をご覧の方向けページ栄院youtube-lp)）
- [ ] **コンバージョンを設定**（栄院の検索広告と同じ Google 広告アカウントで）
  - 主要：「栄院YouTube 予約」＝ GTM のイベント `reservation_complete`（`lp_name` が `sakae_youtube`）
  - 補助：「栄院YouTube LINEタップ」＝ `line_click`、「栄院YouTube 電話タップ」＝ `tel_click`
- [ ] **YouTube チャンネルを Google 広告アカウントにリンク**し、オーディエンス「チャンネルの動画を視聴したユーザー（過去90日）」を作る
- [ ] **L-Message で「栄院YouTubeページ用」の流入経路**を作り、ページの `lineUrl` に設定（ページ経由の友だち追加を数えるため）
- [ ] **広告に使う動画のサムネイルを直す**：「オールオン4を徹底解説」の「専門医がすべて解説！」を変える（[動画ごとの文面](youtube-video-texts.md#タイトルサムネイルで直したいもの)）。広告ではサムネイルも広告の一部です
- [ ] 広告に使う動画の内容が、広告できる範囲に収まっているかを確認（動画広告では、ウェブサイトのような「限定解除」が使えない可能性が高いため。迷う場合は保健所に確認）

| 言語 | 日本語 | |
| 年齢 | 広告グループA：55〜64歳・65歳以上（ご本人）／広告グループB：45〜54歳（ご家族） | 動画を見ている層と、治療を一緒に決めるご家族 |

## 4. 名駅歯科の広告との分担

名駅と栄は約2.5kmしか離れていないため、**地域で配信先を分けることはできません**（どちらの半径にも名古屋市のほぼ全域が入ります）。代わりに、次のように役割で分けます。

| | 栄院（この計画） | 名駅歯科 |
|---|---|---|
| 広告の中心 | 院長・北村の YouTube 動画（解説・案内） | 名駅の LP・名駅の動画 |
| 受け皿 | YouTube をご覧の方向けページ → 栄院の予約 | 名駅の LP → 名駅の予約 |
| 予算 | 両院の YouTube 広告の合計額を、グループで先に決める | 同左 |

同じ人に両院の広告が出ることはありますが、それぞれ自分の医院のページに案内するため、大きな問題にはなりません。予算の合計だけ、グループで管理してください。

## 5. 判断の基準

| 時期 | 見る数字 | 判断 |
|---|---|---|
| 2週間後 | 地域内の視聴単価・視聴率・平均再生率、LINE タップ数（GA4 で `line_click` を広告の流入元別に） | 視聴単価が30円を超える、または視聴率が10%未満なら、動画と対象を見直す |
| 4週間後 | 相談予約数、LINE 友だち追加数（L-Message の経路別） | **予約1件あたり28万円以下**（検索広告と同等以下）なら継続・増額を検討 |
| 4週間後 | 予約0件でも LINE 友だちが10人以上 | 検討期間が長い治療のため、もう1か月続けて LINE の配信から予約が出るかを見る |
| 4週間後 | 予約も LINE 友だちもほぼ0 | 動画（院長の案内動画を作り直す）か対象（年齢・カスタムセグメント）を変える。2か月で変化がなければ止める |

**毎週の報告**として、代理店（または担当者）に次を出してもらうと、判断がぶれません：費用／表示・視聴回数／地域内の割合／年齢別の視聴／LINE タップ／予約／LINE 友だち追加（経路別）／予約1件あたりの費用（**総費用÷総件数**）。
