# YouTube 動画ごとの文面（固定コメント・説明欄・終了画面）

`python3 tools/youtube-texts.py` で生成しています。直接編集せず、スクリプトの文言を直して再実行してください。

- **Webで予約のリンク先**：今は広告用LP（`implant03`）。YouTube をご覧の方向けページ（`youtube-lp/`）を公開したら、スクリプトの `WEB_BASE` を変えて再実行します。UTM（`utm_content=動画ID`）はそのままです
- **LINE**：今は説明欄・固定コメントとも YouTube 用の経路（`dvdWFh`）。固定コメント用の経路を作ったら `LINE_COMMENT` を差し替えます
- 説明欄の **【 】の部分**（目次・別途費用・期間）は、動画と医院の料金表に合わせて記入してください
- 根拠：[計画書9章](youtube-acquisition-plan.md#9-youtube-studio-のデータ2026年10月5日に書き出し)（スマホが58%で固定コメントが最初に目に入る／平均3〜5分で離脱／終了画面からの再生は7回）

## 設定の手順（1本あたり5分）

1. YouTube Studio →「コンテンツ」→ 動画の鉛筆アイコン
2. **説明**：今の説明をすべて消し、下の「説明欄」を貼り付けて【 】を記入 → 保存
3. **終了画面**：「終了画面」→ 下の表のとおりに「動画」「再生リスト」「登録」を配置 → 保存（外部サイトへのリンクは、YouTube パートナープログラムの参加前は置けません）
4. **固定コメント**：動画のページを開き、チャンネルとしてコメントを投稿 →「︙」→「固定」
5. ショートは、説明欄・コメントのリンクを押せないため、**「関連動画」に長い動画を設定**します（ショートの編集画面の「関連動画」）

## タイトル・サムネイルで直したいもの

データ（計画書9章）とガイドライン（計画書5章）から、直す価値が高いものだけを挙げています。それ以外は今のままで大丈夫です。タイトルとサムネイルは、YouTube Studio の「テストと比較」で今のものと比べながら変えると安全です。

| 契約前の必須知識7選 | サムネイル「9割の人が知らずに契約している」 | 根拠を示せない数字（ガイドライン） | サムネイル「契約前に知っておきたい7つ」 |
| オールオン4を徹底解説 | サムネイル「専門医がすべて解説！」 | 「専門医」は広告できない表記（ガイドライン） | サムネイル「院長がすべて解説」 |
