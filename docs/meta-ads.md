# Meta 広告（Instagram・Facebook）の広告文と配信設定

改善版LP（[`lp-006/`](../lp-006/) → `all_on_4_006/`）に合わせた、Meta 広告の広告文・クリエイティブ・配信設定のまとめです。
LPの見出しは、広告のURLの `?v=` で広告ごとに切り替わります（**広告で言ったことが、LPの最初の画面にそのまま出る**＝離脱が減る）。

---

## 1. 先に守るルール

広告そのものにも **医療広告ガイドライン** がかかります。しかも広告（バナー・SNS広告）は、LPと違って「限定解除」ができないため、LPより厳しくなります。あわせて Meta の広告ポリシーも守る必要があります。

| してはいけないこと | 理由 | 代わりに |
|---|---|---|
| 術前・術後写真、口元の変化を並べた画像 | 広告では掲載できない（医療広告ガイドライン）。Meta でも「自分の見た目を否定的に感じさせる」画像は審査で落ちやすい | 医師・院内の写真、治療のしくみのイラスト、笑顔のイメージ（「イメージ」と明記） |
| 患者さんの感想・体験談・口コミの引用 | 体験談は広告できない | 実績（**集計期間を併記**）、医師の言葉 |
| 「あなたの歯は…」「入れ歯でお困りのあなたへ」 | Meta の「個人の特性」ポリシー（相手の健康状態を知っているような表現）に違反 | 「入れ歯のずれ・痛みでお悩みの方へ」「〜という選択肢」 |
| 「痛くない」「必ず」「1日で完了」「No.1」「地域トップクラス」 | 誇大・断定・比較 | 「うとうとした状態で手術を受けられます」「手術当日に固定式の仮歯」 |
| 「今だけ半額」「激安」など費用を強調 | 品位を損ねる広告とされる | 標準的な費用を事実として書く |
| 費用を書かずに自由診療を広告 | 自由診療は内容と標準的な費用の併記が必要 | 「自由診療／手術費用 片あご1,925,000円（税込）。麻酔・上部構造等は別途」 |

- 美容・医療の広告は **18歳以上** に配信する設定にします
- 主なリスク（術後の腫れ・痛みなど）も、広告文の最後に短く入れておくと安全です

## 2. 広告の組み合わせ（見出しパターン）

| パターン | 誰に | LPのURL（`all_on_4_006/` の後ろ） | LPの最初の見出し |
|---|---|---|---|
| A. 標準 | 入れ歯・歯の悩みがある方 | （なし） | オールオン4で、噛める喜びを取り戻す。 |
| B. 入れ歯 | 入れ歯のずれ・痛みが気になる方 | `?v=denture` | もう、入れ歯を外さない毎日へ。 |
| C. 手術が怖い | 痛み・手術への不安が強い方 | `?v=fear` | うとうとした状態で、手術を受けられます。 |
| D. 費用 | 費用を気にしている方 | `?v=price` | オールオン4（片あご）1,925,000円（税込） |
| E. 骨が少ない | 他院で難しいと言われた方 | `?v=bone` | 骨が少なくても、治療できる可能性があります。 |
| F. ご家族 | 親の歯が心配な子ども世代（40〜50代） | `?v=family` | 親の「噛める喜び」を、もう一度。（フォームも「ご家族のご相談」に） |

`?v=` を付けなくても、広告名（`utm_content`）に「入れ歯」「費用」「骨」「怖い」「家族」などが入っていれば自動で切り替わります。

## 3. 広告文（そのまま使えます）

Meta の広告文は、最初の約125文字までが「…もっと見る」の前に表示されます。**最初の2行に「誰の・どんな悩みに・何が」**を入れています。

### A. 標準（画像：理事長の写真＋実績。現在の006のメイン画像と同じ構図）
- **メインテキスト**
  ```
  入れ歯のずれ・痛みや、グラグラする歯でお悩みの方へ。
  オールオン4は、4本のインプラントで片あごの歯を支える治療法です。手術当日に固定式の仮歯が入ります（骨の状態により異なります）。

  ・CT撮影つきの無料カウンセリング
  ・麻酔専門医が常駐（静脈内鎮静法・全身麻酔に対応）
  ・JR名古屋駅から徒歩2分

  自由診療：手術費用 片あご1,925,000円（税込）。麻酔・上部構造等は別途。術後に腫れ・痛みが出ることがあります。
  ```
- **見出し**：オールオン4で、噛める喜びを
- **説明**：名駅歯科クリニック｜名古屋駅徒歩2分
- **ボタン**：詳しくはこちら（「予約する」と比べるテストも）

### B. 入れ歯（`?v=denture`）
- **メインテキスト**
  ```
  食事のたびに入れ歯がずれる、外れる、痛い――。
  オールオン4は、4本のインプラントで歯を固定する治療法。毎晩の取り外しが不要になります。手術当日に固定式の仮歯が入ります（骨の状態により異なります）。

  まずはCT撮影つきの無料カウンセリングで、治療できるかをご確認ください。
  自由診療：手術費用 片あご1,925,000円（税込）。麻酔・上部構造等は別途。
  ```
- **見出し**：入れ歯から、固定式の歯へ
- **説明**：30秒の適応チェックつき

### C. 手術が怖い（`?v=fear`）
- **メインテキスト**
  ```
  「インプラントの手術が怖い」という方へ。
  当院は麻酔専門医が常駐し、すべての手術に麻酔医が立ち会います。点滴で鎮静薬を使う静脈内鎮静法なら、うとうとした状態で手術を受けられます。全身麻酔にも対応しています。

  オールオン4の無料カウンセリング受付中（CT撮影つき）。JR名古屋駅から徒歩2分。
  自由診療：手術費用 片あご1,925,000円（税込）。麻酔費用は別途。
  ```
- **見出し**：麻酔専門医が常駐しています
- **説明**：静脈内鎮静法・全身麻酔に対応

### D. 費用（`?v=price`）
- **メインテキスト**
  ```
  オールオン4の費用、はっきりお伝えします。
  手術費用は片あご1,925,000円（税込。CT撮影・画像診断を含む）。デンタルローンなら月々19,000円台から。医療費控除の対象にもなります。

  麻酔・上部構造（最終的な歯）などは別途かかります。お口の状態を診断したうえで、治療を始める前に総額をご説明します。
  ```
- **見出し**：片あご1,925,000円（税込）
- **説明**：月々19,000円台〜・医療費控除の対象

### E. 骨が少ない（`?v=bone`）
- **メインテキスト**
  ```
  他院で「骨が足りない」「インプラントは難しい」と言われた方へ。
  オールオン4は、奥のインプラントを斜めに埋め込むことで、骨の少ない部分を避けて治療できる場合があります。上あごの骨が少ない方には、頬骨を利用するザイゴマインプラントという選択肢も。

  まずはCTで骨の状態を確認しませんか？（初回相談・CT撮影は無料）
  自由診療：手術費用 片あご1,925,000円（税込）。麻酔・上部構造等は別途。
  ```
- **見出し**：骨が少なくても、ご相談ください
- **説明**：CT撮影つき無料カウンセリング

### F. ご家族（`?v=family`、40〜59歳に配信）
- **メインテキスト**
  ```
  親御さんの入れ歯のことで、気になっていることはありませんか？
  オールオン4は、4本のインプラントで片あごの歯を支える固定式の治療法です。手術当日に固定式の仮歯が入ります（骨の状態により異なります）。

  カウンセリングにはご家族も同席できます。JR名古屋駅から徒歩2分。
  自由診療：手術費用 片あご1,925,000円（税込）。麻酔・上部構造等は別途。
  ```
- **見出し**：ご家族と一緒にご相談ください
- **説明**：CT撮影つき無料カウンセリング

## 4. クリエイティブ（画像・動画）

| 種類 | 内容 | ポイント |
|---|---|---|
| 画像（A） | 理事長の写真＋「オールオン4で、噛める喜びを取り戻す」＋実績3つ（**2024年1〜12月の実績** と明記） | 現在の006のメイン画像と同じ構図。LPの最初の画面と見た目がそろう |
| 画像（C） | 麻酔医（河合先生）または院内のオペ室の写真＋「麻酔専門医が常駐」 | 不安の強い層に |
| 画像（D） | 料金カード（片あご1,925,000円（税込）／月々19,000円台〜） | 数字は大きく。「麻酔・上部構造等は別途」を小さく併記 |
| 動画（リール・ストーリーズ） | 医院の解説動画（「All-on-4で笑顔を取り戻す」）の冒頭15〜30秒＋最後に医院名・名古屋駅徒歩2分 | **縦型（9:16）に作り直す**と表示面積が大きくなる。音なしでも分かるよう字幕を |

- 画像の文字は少なめに（スマホで読める大きさ）。医院名と「名古屋駅徒歩2分」はどの画像にも
- 「術前→術後」の比較画像、歯の状態が悪い口元のアップは使わない（1章）
- 同じ画像を長く出し続けると反応が落ちます。**2〜4週間ごと**に1〜2本入れ替え

- **ウェブサイトのURL**：`https://www.meieki-dental.net/all_on_4_006/`（パターンに応じて `?v=denture` などを付ける）
- **URLパラメータ**（広告の［トラッキング］→［URLパラメータ］）
  ```
  utm_source=meta&utm_medium=paid_social&utm_campaign={{campaign.name}}&utm_term={{adset.name}}&utm_content={{ad.name}}
  ```

## 6. 配信の設定

| 項目 | おすすめ | 理由 |
|---|---|---|
| キャンペーンの目的 | **売上**または**リード**（ウェブサイトでのコンバージョン） | 「予約しそうな人」に配信を寄せるため |
| 最適化するイベント | **Lead**（予約完了ページの `reservation_complete`） | 計測の設定は [`measurement-setup.md` の7章](measurement-setup.md#7-meta広告instagramfacebookの計測) |
| 地域 | 名古屋駅から半径20〜30km（愛知・岐阜・三重の通院圏）。必要なら市区町村で調整 | 来院できる範囲に絞る |
| 年齢 | ご本人向け：50〜75歳以上／ご家族向け（F）：40〜59歳。どちらも18歳以上 | 治療を受ける年代と、親の治療を考える子ども世代 |
| 配置 | Advantage+ 配置。ただし **Audience Network は様子を見て除外** | アプリ内の誤タップが多く、予約につながりにくいことが多い |
| 広告セットの数 | 予約が少ないうちは **1〜2個に集約** | Meta は1広告セットあたり週50件前後の最適化イベントで学習が安定する。分けすぎると学習が進まない |

### 予約（Lead）が少ないうちは
- 週の予約数が少ないと配信の学習が進みにくくなります。その場合は、予約より手前の行動（**30秒チェックの完了 `quiz_complete`** など）をカスタムコンバージョンにして最適化する方法もあります。ただし、手前の行動で最適化すると「チェックはするが予約しない人」も増えるため、予約単価を見ながら判断してください
- 医療・健康の分野の広告主は、Meta 側でイベントの使い方が制限されることがあります。イベントマネージャに制限の表示が出た場合は、その案内に従って最適化イベントを選び直してください

## 7. 数字の見方（どこで止まっているか）

| 指標（広告マネージャ・GA4） | 低いときに疑うこと | 打ち手 |
|---|---|---|
| リンクのクリック率 | 広告の画像・最初の2行 | パターンA〜Fの入れ替え・新しい画像 |
| ランディングページビュー ÷ リンクのクリック | LPの表示が遅い・広告と内容が違う | LPの表示速度（改善版は約285KB）、広告とLPの見出しをそろえる |
| 30秒チェックの開始率（`quiz_start`） | 最初の画面で興味を持てていない | 見出しパターン・最初の画面の写真 |
| チェック完了 → 予約フォーム開始（`form_start`） | 結果の内容・予約ボタンの文言 | 結果のアドバイス文、LINE（小冊子）への誘導 |
| フォーム開始 → 予約完了 | 入力の負担・日時の選択肢 | 予約枠（`CONFIG.timeSlots`）、電話での予約案内 |
| 予約 → 来院 | 電話のスピード・内容 | [`reception-manual.md`](reception-manual.md)（当日中の電話が最優先） |

予約台帳の「見出しパターン」「utm_content（広告名）」で、**どの広告・どの見出しから来た予約が来院・成約につながったか** まで確認できます。予約数だけでなく、来院・成約の多いパターンに予算を寄せてください。
