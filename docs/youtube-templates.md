## 7. YouTube 広告の設定案

> 実績データ（検索広告の相談1件あたり約28万円など）をもとにした詳細版・広告文・院長の案内動画の台本は [`youtube-ads-plan.md`](youtube-ads-plan.md) にあります。以下は最初に作った概要です。

グループ（広告主「医療法人スマイル」）ですでに名駅歯科の動画広告を出している Google 広告アカウントで作ります。まず1か月テストし、数字で判断します。

**始める前にグループで決めること**

- **名駅歯科の動画広告との分担**：名駅と栄は約2.5kmしか離れていないため、地域では分けられません。役割（栄院は院長の YouTube 動画、名駅は名駅のLP）で分け、両院の予算の合計をグループで決めます（[`youtube-ads-plan.md` 4章](youtube-ads-plan.md#4-名駅歯科の広告との分担)）
- **広告に使う動画の確認**：動画広告では、自由診療の「限定解除」が使えない可能性が高いと考えられます。広告に使う動画は、広告できる内容に収まっているかを、名駅歯科の動画広告と同じ流れで確認してください（迷う場合は保健所に確認）

### 事前準備

1. YouTube チャンネルを Google 広告アカウントにリンクする（Google 広告 →「ツール」→「データ マネージャー」→ YouTube）
2. オーディエンスを作る：「チャンネルの動画を視聴したユーザー」「チャンネル登録者」
3. L-Message で「栄院youtube広告」の流入経路を作り、YouTube を見た人向けのページのLINEボタンに使う
4. コンバージョン：Web予約の完了、LINEボタンのクリック、電話ボタンのタップ

### キャンペーン1：既存動画を地元に届ける（動画の視聴を増やすキャンペーン）

| 項目 | 設定 |
|---|---|
| 地域 | 【名古屋市＋通院圏の市町村／愛知県全域／岐阜県南部・三重県北部】 |
| 地域の対象 | **「所在地：対象地域にいる、または定期的にいるユーザー」だけ**にする（初期設定の「地域に関心がある人」を含めると、全国に配信されてしまう） |
| 年齢 | 広告グループA：55〜64歳・65歳以上（ご本人）／広告グループB：35〜54歳（ご家族） |
| 配信面 | インフィード（検索結果・関連動画）とショート。押して見たときだけ費用がかかる形から始める |
| オーディエンス | カスタムセグメント：Google で「インプラント 名古屋」「オールオン4」「入れ歯 合わない」「総入れ歯」「インプラント 費用」などを検索した人 |
| 動画 | オールオン4を徹底解説、オールオン4の費用、何歳まで可能？、選択肢3つを比較（検討している人が長く見ている動画。計画書9章）。広く届ける1本として、オススメしない方10選 |
| 予算 | 1日1,000〜1,500円（月3〜5万円） |
| 見直し | 2週間ごと。地域内の視聴単価、視聴者維持率、チャンネルへのクリック、LINE追加数 |

### キャンペーン2：見た人にもう一度（リマーケティング）

| 項目 | 設定 |
|---|---|
| 対象 | 「チャンネルの動画を視聴したユーザー」（過去90日）× 上と同じ地域 |
| 検索広告 | 既存の検索広告キャンペーンに、このオーディエンスを「モニタリング」で追加し、入札を強める |
| 動画・ディスプレイ | 院長の30〜60秒の「無料相談のご案内」動画（新しく撮影）→ YouTube を見た人向けのページ |

### 判断の目安

- **LINE友だち1人あたり・相談予約1件あたりの広告費**で判断します。オールオン4は片あご175万円（税別）なので、相談から成約が1件出れば、テスト費用を大きく上回ります
- 1か月でLINE追加・相談予約がほとんど出ない場合は、地域・年齢・動画を見直してから続けるか判断します
