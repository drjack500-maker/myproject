# 予約リクエスト 受付対応マニュアル

LPの予約フォームは「予約リクエスト」を受け付ける仕組みです。**医院からの電話で日時を確定して、はじめて予約完了**になります。連絡が早いほど来院につながるため、この手順で対応してください。

---

## 1. 全体の流れ

```
患者さまがLPから送信
   ↓ 通知メールが届く／予約台帳（スプレッドシート）に1行追加（対応状況：未対応）
① できるだけ早く電話（目標：1時間以内、遅くとも当日中）
   ↓ つながった
② 日時を確定し、予約システム（Apotool）に登録
③ 台帳の「対応状況」を「予約確定」に更新
④ 前日にリマインドの電話（またはSMS）
⑤ 来院後、台帳に「来院日時」、治療が決まったら「成約日時・成約金額」を記入
```

## 2. 電話のタイミング

- 通知メールが届いたら、**できるだけ早く**お電話してください。時間がたつほど、他院に予約したり、気持ちが冷めたりしてつながりにくくなります
- 「お電話のご都合のよい時間帯」が入力されていれば、その時間帯を優先します
- 休診日（土日祝）や診療時間外に届いたリクエストは、**翌診療日の午前中**に最優先で対応します
- Instagram・Facebook の広告から来た方（台帳の「流入ページ」が `all_on_4_006`、utm_source が `meta`）は、検索して来た方より「まだ検討を始めたばかり」のことが多いです。日時の確定を急がせず、**「ご相談だけでも大丈夫です」「ご家族と一緒でも大丈夫です」** を添えてください
- 「ご相談内容」には、LPの30秒チェックの回答（「他院でインプラントを断られた」「手術の痛み・怖さ」など）も入ります。電話の最初に触れると話が早く進みます（例：「骨が少ないと言われたとのこと、当日はCTで詳しく確認しますね」）

## 3. 電話のトーク例

> こちらからおかけする電話なので、最初に名乗って用件を伝えます。

1. **名乗る**
   「名駅歯科クリニックの〇〇と申します。ホームページから無料カウンセリングのご予約をいただいた、△△様のお電話でよろしいでしょうか。」
2. **お礼と確認**
   「ご予約のお申し込み、ありがとうございます。第1希望の□月□日（□）午後で、お取りできます。」
   （希望日時が埋まっている場合）「あいにくその時間は埋まっておりまして、□日の□時はいかがでしょうか。」
3. **予約システム（Apotool）に登録**（初診・無料カウンセリング）
4. **ご案内**
   - 「当日はCT撮影を含めて、1時間ほどお時間をいただきます。」【所要時間は医院の実際に合わせて変更】
   - 「健康保険証、お薬手帳（お薬を飲んでいる方）、今お使いの入れ歯をお持ちください。」
   - 「ご家族とご一緒でも大丈夫です。」
   - 「名古屋駅の3番出口から徒歩2分、名駅モリシタビルの8階です。」
5. **不安の確認**
   「ほかに、ご不安なことやご質問はございますか？」（費用・痛み・持病などは、当日くわしくご説明する旨を伝える）
6. **締め**
   「前日にもう一度ご確認のお電話をさせていただきます。当日お会いできるのを楽しみにしております。」

## 4. つながらないとき

| 回数 | タイミング | 対応 |
|---|---|---|
| 1回目 | 受信後すぐ | 留守番電話にメッセージを残す（下記） |
| 2回目 | 当日の夕方 | もう一度電話 |
| 3回目 | 翌診療日の午前 | もう一度電話。メールアドレスがあればメールも送る |

**留守番電話のメッセージ例**
「名駅歯科クリニックの〇〇です。ホームページからのご予約の件でお電話いたしました。改めてご連絡いたしますが、お手数ですが 052-571-3345 までお電話いただけましたら幸いです。受付は平日9時から19時です。」

3回つながらない場合は、台帳の「対応状況」を「連絡済み」のままにし、「対応メモ」に経緯を書いておきます。

## 5. 予約台帳の更新

| 対応状況 | いつ選ぶか |
|---|---|
| 未対応 | （自動）受け付けたばかり |
| 連絡済み | 電話したが、まだ日時が確定していない |
| 予約確定 | 日時が決まり、Apotool に登録した |
| 来院 | カウンセリングに来院した（「来院日時」も記入） |
| 成約 | 治療が決まった（「成約日時」「成約金額」も記入） |
| 失注 | 来院したが治療に至らなかった |
| キャンセル | 予約をキャンセルした／連絡がつかなかった |
| スパム疑い | （自動）いたずらの可能性がある送信。通知メールは届きません。**週に1回は中身を確認**し、本物の予約なら「未対応」に変えて電話してください |

- 未対応の行は黄色で表示されます。**1日の終わりに黄色の行が残っていないか確認**してください
- 「来院日時」「成約日時」「成約金額」は、広告の最適化に使います（スプレッドシートのメニュー［LP予約］→［広告CV取り込みシートを更新］）。月に1回以上の更新をおすすめします

## 6. 前日のリマインド

- 予約前日（休診日をはさむ場合は直前の診療日）に確認のお電話をします
- 「明日□時にお待ちしております。お気をつけてお越しください。」
- 都合が悪くなった場合は、その場で別の日時を提案します

## 7. 毎月見る数字

| 指標 | 計算 | 目安にする使い方 |
|---|---|---|
| 初回連絡までの時間 | 受付日時 → 最初の電話 | 遅くなっていないか |
| 予約確定率 | 予約確定以上 ÷ リクエスト数 | 電話がつながっているか |
| 来院率 | 来院以上 ÷ 予約確定 | リマインドが機能しているか |
| 成約率 | 成約 ÷ 来院 | カウンセリングの内容・フォロー |

「対応状況」の列で絞り込むと、それぞれの件数を数えられます。
