| ファイル | 内容 |
|---|---|
| `index.html` | 改修版（公開するのはこのファイル。写真は医院サイトの画像を読み込む） |
| `preview.html` | 確認用の1ファイル版（写真と見出しフォントを埋め込み済み。ダブルクリックやメール・チャットの添付でそのまま開ける。GTMなし） |

`index.html` を直したら、`npm run build:ultimate-preview` で `preview.html` を作り直してください（写真とフォントをネットから取得します）。

## 変更内容

文言・リンク先・計測（GTM と `data-cta`）・見出しの出し分け（`?t=bone` / `denture` / `fear`）は改修前と同じです。変えたのは見た目だけです。

例外として、ご指示により費用表の「オールオンフォー（片顎）」の項目を変更しました（「最終補綴（最終的な歯）」を削除し、「ロケーター 962,500円」を追加）。ザイゴマインプラントの費用は「骨の状態・治療内容に応じて個別にお見積りします。」と表示しています。
また、費用表から「上部構造（被せ物・1本）」「1本あたりの総額目安」「静脈内鎮静法」「全身麻酔」の行と、表の下の注記2行（自由診療である旨・追加処置で総額が変わる旨）を削除しました。自由診療である旨は、治療法の各説明とリスクの一覧に残っています。
治療期間の表（期間・通院回数）と10年保証（保証対象・適用除外）は内容確定のため黄色の網掛けを外し、「お支払い方法」の支払例（デンタルローンの月々の金額など）は削除しました。

### 写真・イラスト

- **写真**：医院の既存写真（`https://www.ultimate-dental.com/implant03/assets/img/`）を大きく使用。治療法の3Dイラスト（`plan_img01〜03.png`）は 96px の小さな表示から、カード上部の大きな表示に変更
- **イラスト（SVGで新規作成、HTMLに埋め込み）**
  - インプラントの構造（被せ物・土台・人工歯根）の立体イラスト：FV写真の上と予約ボタン帯の背景
  - 「入れ歯・ブリッジ・インプラント」の比較図：お悩みセクション
  - アイコン：FVの3つの特長、流れの各ステップ、費用まわりの囲み、リスク、電話・LINE・予約ボタン
- **小冊子の画像**：LINEボタン（FV・中間と最後の予約ボタン帯）に小冊子「知らないと後悔するインプラント治療の真実」の表紙を表示。名駅歯科クリニックのLP（同じLINE・同じ小冊子）のバナー `https://www.meieki-dental.net/all_on_4_004/assets/img/line001.png` から表紙だけを切り抜き、WebP（約11KB）にして `index.html` のCSSに埋め込んでいるため、画像ファイルを別にアップロードする必要はありません

### 立体感の出し方

- 影を重ねたカード（お悩み・治療法・流れ・医師・FAQ・医院情報）
- 立体ボタン（押すと沈む）、球体のアイコン
- FV写真を奥行きのある配置にし、PCではマウスの動きに合わせて傾く
- 写真の後ろに金色の枠をずらして重ね、番号（01〜04）を大きく表示
- スクロールで要素が浮かび上がる演出（端末で「視差効果を減らす」を設定している場合と、JavaScriptが無効の場合は演出なしで表示）

### そのほか

- 見出しに明朝体（Google Fonts の Noto Serif JP）を追加
- スマホで費用表の金額が横スクロールしないと見えなかった点を修正（期間の表は3列のため従来どおり横スクロール）
- スマホでヘッダー（ロゴと電話番号）が画面幅からはみ出し、ページ全体が横にずれていた点を修正
- タブレット幅（720〜999px）で予約ボタンが3列に詰まり文字が折り返していた点を修正（LINEボタンを1段目に広く、Web予約・電話を2段目に並べる。PCではLINEボタンの幅を広めにした3列）
- HTML検証のエラーを 16件 → 1件に（残りの1件は GTM 公式の `noscript` タグ）
