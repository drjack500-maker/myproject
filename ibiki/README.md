# となりのいびき相談室（いびきコンテンツ販売）

夫・パートナーのいびきで眠れない人に向けて、歯科医師が「記録 → 伝える → 正しい順番で相談する」を教えるコンテンツ事業の制作物です。
**医療法人（医院）とは別の事業として運営する前提**で、医院名・症例・自院への案内は入れていません。

## 導線

```
ショート動画（毎日）・音声（週3）・YouTube長尺（週1）
  ↓ プロフィールのリンク
LP（lp/）→ LINE友だち追加
  ↓
無料：いびきタイプチェック＋7日間の音声講座＋伝え方シート（line/）
  ↓ 7日目
30日いびき記録キット 2,980円 → 30日プログラム 19,800円 → 月額クラブ 2,980円
```

## LPの公開前にやること

1. `lp/assets/js/main.js` の `CONFIG.lineUrls` に、L Message で発行した流入経路URLを入れる
   - SNSのプロフィールには `?src=tiktok` `?src=instagram` などを付けたLPのURLを置くと、流入元ごとのURLに切り替わる
   - 未設定のままだと、LINEボタンは止まり「準備中」と表示される
2. 計測する場合は `CONFIG.gtmId` と `CONFIG.prodHosts`（公開ドメイン）を設定
3. `lp/index.html` の `og:url` `og:image` を公開URLに合わせる
4. 【講師名】【運営者名】【メールアドレス】【制定日】を埋める（`index.html` `privacy.html`）
5. 講師の顔写真を入れる（`index.html` の「お話しするのは」。今はシルエット）
6. ファーストビューのクマ夫婦は仮のイラスト。ショート動画用にAIで作ったキャラクターができたら差し替える（差し替え後は `npm run build:ibiki-images` でOGP画像も作り直す）

## 手元での確認とテスト

```bash
npm run serve:ibiki          # http://localhost:8000/ でLPを確認
npm test                     # HTML検証＋ブラウザテスト（医院LPと一緒に実行）
npm run build:ibiki-images   # OGP画像・ホーム画面アイコンを作り直す
```

テストで確認していること：LINEのURL未設定時の停止と案内／流入元ごとのURL切り替えと保持／https以外のURLを使わない／クリック計測／本番ドメイン以外で計測タグを読まない／スマホの最初の画面にボタンが入る／追従ボタンの表示切り替え／幅360pxで横スクロールなし／アクセシビリティ（axe）。

## 運営上の注意（要点）

- 販売は医療法人ではなく、理事長個人か別会社で行う（医療法人は一般向けの講座を売れない）。税理士・行政書士に確認
- 医院名・症例・自院への誘導を入れない（入れると医療広告の規制対象になる）
- 「治る」「必ず」と言い切らない。個別の診断をしない。グッズを効果つきですすめない
- 販売ページには特定商取引法に基づく表記と最終確認画面を用意する。Zoomなどの個別相談では売らない
- 載せている調査の数字は、出典と母数を確認済みのものだけ（LPのフッターに出典を記載）
