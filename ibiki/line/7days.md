# LINE 7日間ステップ配信（となりのいびき相談室）

LINE公式アカウント（L Message）で、友だち追加からキットの案内までを自動で届ける配信文一式です。
そのまま貼り付けられるように、本文は `---` で区切っています。

| 項目 | 内容 |
|---|---|
| アカウント名 | となりのいびき相談室 |
| 話し手 | いびき先生（歯科医師・【講師名】） |
| 主な読み手 | 夫・パートナーのいびきで眠れない40〜60代の女性（自分のいびきが気になる人にも対応） |
| 無料プレゼント | ①いびきタイプチェック（2分）②7日間の音声講座（各3分）③ケンカにならない伝え方シート（[tsutaekata-sheet.md](tsutaekata-sheet.md)） |
| ゴール | 7日目に「30日いびき記録キット」（2,980円）を案内。呼吸が止まるサインがある人には、商品より先に受診をすすめる |
| 配信時刻 | 0日目＝チェック回答の直後／1〜7日目＝毎晩 20:30（家事が落ち着き、寝る前に読める時間） |

> **守ること**：医院名・症例・自院への案内は書かない／「治る」「必ず」「改善します」と言い切らない／個別の診断はしない（一般的な情報と受診のすすめまで）／グッズを効果つきですすめない。詳しくは末尾の「NG表現チェック」。

## 3. いびきタイプチェック（設問と判定）

L Message の回答フォームで作ります。選択肢はすべてボタン（1つ選ぶ）。

| # | 設問 | 選択肢（→付けるタグ） |
|---|---|---|
| Q1 | 気になっているのは、どなたのいびきですか？ | 夫・パートナー（→対象_相手）／自分（→対象_本人）／親・ほかの家族（→対象_相手） |
| Q2 | いびきは、週に何日くらいですか？ | ほぼ毎晩／週に2〜4日／たまに（お酒を飲んだ日など） |
| Q3 | いびきの途中で音が止まり、しばらくして「ガッ」「ゴホッ」と大きく息を吸うように再開することがありますか？ | よくある（→サイン）／ときどき（→サイン）／ない／わからない |
| Q4 | いびきをかく人は、昼間に強い眠気がありますか？（会議中や運転中にうとうとする など） | ある（→サイン）／ない／わからない |
| Q5 | いびきをかく人は、朝起きたとき、のどや口がカラカラになっていますか？ | よくある（→鼻口）／ときどき（→鼻口）／ない／わからない |
| Q6 | お酒を飲んだ夜や、疲れた夜に、いびきが大きくなりますか？ | はい（→習慣）／いいえ／わからない |
| Q7 | いびきをかく人は、ここ数年で体重が増えましたか？（目安：5kg以上） | はい（→習慣）／いいえ／わからない |
| Q8 | いびきをかく人は、鼻がつまりやすい、または口を開けて寝ていますか？ | はい（→鼻口）／いいえ／わからない |
| Q9 | いびきをかく人は、高血圧と言われたことがありますか？ | はい／いいえ／わからない |

※Q1で「自分」を選んだ人には、Q4以降の「いびきをかく人は」を「あなたは」に読み替えてもらう前提で、同じ設問のままで構いません（フォームを2つ作る手間を省くため）。

### 判定ルール（上から順に、最初に当てはまったもの）

1. **タイプC（一度、医療機関で確かめたいタイプ）**：`サイン` がついた（Q9「はい」はQ2「ほぼ毎晩」のときだけ `サイン`）
2. **タイプB（鼻・お口ぽかんタイプ）**：`鼻口` がついた
3. **タイプA（お疲れ・お酒タイプ）**：上のどちらでもない

> Q9（高血圧）は単独では `サイン` にしません。高血圧の人は多く、それだけで「受診を急ぐ」と出すと、不安をあおりすぎるためです。

### 1日目：いびきと「無呼吸」は、同じではありません

**LINE本文**

---

【1日目】
いびきと「無呼吸」は、同じではありません。

いびきは、眠っているあいだに のどが狭くなり、空気の通り道がふるえて出る音です。
多くのいびきは「音」の問題。

でも、気をつけてほしいのは
「音が止まる」いびきです。

グー、グー、
……（静か）……
ガッ！

この「静かな時間」に、呼吸が止まったり、浅くなったりしていることがあります。
これが眠るたびにくり返される状態が、睡眠時無呼吸症候群です。

大事なのは、うるさいかどうかより、止まるかどうか。

今夜、となりの人の寝息に、ほんの少しだけ耳を澄ませてみてください。

【音声URL：day1】

---

**画像**：横長カード。左「グー、グー（いびき）」右「……ガッ！（止まって再開）」。下に「気をつけたいのは、右」。

**音声の台本（約3分）**

> こんばんは。となりのいびき相談室の、いびき先生です。7日間の1日目、今日は「いびき」と「無呼吸」の違いについて、お話しします。
>
> まず、いびきの正体から。私たちは眠ると、体の力が抜けますよね。のどのまわりの筋肉もゆるみます。すると、空気の通り道が少し狭くなる。狭いところを空気が通ると、まわりがふるえて音が出る。これが、いびきです。ですから、いびきそのものは、珍しいことではありません。お酒を飲んだ夜や、疲れた夜に、誰でもかくことがあります。
>
> 気をつけたいのは、その先です。通り道がもっと狭くなって、ふさがってしまうと、空気が通らなくなる。つまり、呼吸が止まる。しばらくすると、体が苦しくなって目を覚ますように、「ガッ」と大きく息を吸い込む。そしてまた、いびきが始まる。これが一晩に何十回、何百回とくり返される状態が、睡眠時無呼吸症候群です。
>
> 日本では、治療が必要な程度の人だけでも、約900万人いると推計されています。2019年の国際的な研究の数字です。ところが、実際に治療を受けている人は、その1割にも届いていません。多くの人が、気づかないまま眠っています。なぜ気づかないのか。理由は簡単で、眠っている本人には、自分のいびきが聞こえないからです。
>
> だからこそ、となりで眠るあなたの耳が、いちばん大事な「検査」の入り口になります。うるさいかどうか、ではなく、止まるかどうか。今夜、少しだけ耳を澄ませてみてください。グー、グー、と続いたあとに、静かになって、ガッと再開する。そんな音が何度も続くようなら、それは体からのサインかもしれません。
>
> 明日は、そのサインを「記録」する方法をお話しします。記録があると、本人に伝えるときも、医療機関で相談するときも、ぐっと話が早くなります。それでは、今夜はゆっくり、おやすみなさい。

3. **あいさつ**：2章の本文＋回答フォームのボタン
4. **回答フォーム**：3章の9問。回答ごとにタグを付けるアクションを設定
5. **タイプ判定**：回答完了時のアクションで、`サイン` → `タイプC`、なければ `鼻口` → `タイプB`、どちらもなければ `タイプA` を付ける（条件分岐が組めない場合は、タイプごとに3本のシナリオを用意し、タグ条件で振り分け）
6. **0日目**：タイプ別の結果（①）→ 1分後に「今夜の3つの工夫」（`対象_相手`／`対象_本人` で出し分け）→ `タイプC` のみ10分後に3日目の本文
7. **ステップ配信**：1〜7日目を「回答完了の翌日から毎日20:30」に設定。8日目・10日目は `購入_キット` を除外
8. **購入連携**：MOSH の購入完了後に表示するページへ、L Message の「タグ付けURL」を置き、`購入_キット` を付ける（できない場合は購入者リストを週1回CSVで取り込み）
9. **テスト**：自分のLINEで、A・B・C と相手・本人の6通りを最後まで受信して確認

### 毎週見る数字

| 指標 | 見方 |
|---|---|
| 友だち追加 → チェック回答率 | 低ければ、あいさつ文とボタンの位置を見直す |
| タイプの比率 | C が極端に多い／少ない場合は設問の言い回しを見直す |
| 1日目・4日目・7日目の開封率 | どこで離れているか |
| 7日目 → キットのページを開いた率・購入率 | 7日目の本文とページの一致 |
| 「受診した」と答えた人の数 | 30日プログラム修了時のアンケートで集計（この事業の成果として発信できる数字） |

## 9. NG表現チェック

配信文を書き足すときは、次の表で確認してください。

| 使わない | 代わりに |
|---|---|
| いびきが治る／止まる／改善します | いびきを大きくする条件を減らす／変化に気づきやすい |
| 必ず／絶対／100% | 〜という人が多いと言われています／〜のことがあります |
| あなたは睡眠時無呼吸症候群です／〜の可能性が高いです | 一度、医療機関で確かめたいサインがあります |
| このテープ（グッズ）でいびきが止まる | （グッズの効果はうたわない。紹介するなら使い方と注意点だけ） |
| 〇〇歯科で診てもらえます（医院名） | 睡眠外来・呼吸器内科・耳鼻咽喉科、マウスピースは歯科 |
| 受講者の「いびきが消えました！」という声 | （治療効果の体験談は使わない。「受診した人の数」など事実を使う） |
| 今だけ半額／残り3名（事実でない） | 実際の定員・実際の締切だけを書く |

- 呼吸が止まる・昼間の強い眠気などのサインがある人には、どの配信でも「受診が先」と書く
- 販売ページには、特定商取引法に基づく表記（販売者・所在地・連絡先・返品条件など）と、申し込み前の最終確認画面を用意する
- 個別相談で販売しない（Zoomなどで1対1で売ると電話勧誘販売の扱いになり、クーリング・オフなどの義務が生じる）
