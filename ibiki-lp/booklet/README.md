# マンガ小冊子「私の眠りの記録」

いびき改善プログラム「静寂の夜メソッド」（仮称）の**無料小冊子**です。A5・20ページ。LINE登録やメールアドレス登録の特典として配る想定です。

- 配布用PDF：[`nemuri-kiroku.pdf`](nemuri-kiroku.pdf)（約8MB）
- 画面で見る：`npm run serve:ibiki` → http://localhost:8000/booklet/

## 中身

| ページ | 内容 |
|---|---|
| 1 | 表紙（カラー） |
| 2 | はじめに・登場人物・もくじ |
| 3〜5 | 第1話「午前2時の寝室」：妻に「もう、別の部屋で寝て」と言われ、録音して自分のいびきを知る |
| 6〜9 | 第2話「ふくろう先生あらわる」：いびきのしくみと4つの原因（寝姿勢・筋肉のゆるみ・口呼吸・寝る前のお酒）。**病院に相談すべきサイン**と、耳鼻咽喉科での相談 |
| 10〜12 | 第3話「7日間の記録」：1日目 録音 → 2日目 横向き → 3日目 舌の位置 → 4日目 体操 → 5日目 鼻呼吸 → 6日目 夜の習慣 → 7日目 もう一度録音 |
| 13〜14 | 第4話「静かになったね」：数週間後。読者への呼びかけで終わる |
| 15 | セルフチェック（LPと同じ8項目＋受診の目安3項目） |
| 16 | 「眠りの記録」のつけ方 |
| 17〜18 | 眠りの記録シート（7日分）と1週間のふりかえり（書きこみ式） |
| 19 | 今夜からできる5つの習慣（7日分のチェック欄つき） |
| 20 | 裏表紙：プログラムの案内（QRコード・URLは差し替え） |

マンガは日本のマンガと同じく**右上のコマから左下へ**読み、セリフは縦書きです。LPのタイトル案3（「妻に『もう別の部屋で寝て』と言われた…」）を物語の始まりに、タイトル案8（「静かになったね」と言われる日）を結末にしています。

## 配布前に差し替えるところ

- **裏表紙のQRコードとURL**（`pages.js` の 20ページ目、`.qr-box` と `https://〇〇〇〇〇〇`）。QRコードは画像を `img/` に入れて `.qr-box` の中身を `<img>` に替える
- **発行者**（20ページ目「発行：〇〇〇〇」）
- **プログラム名・内容**：「静寂の夜メソッド」「毎晩10分」などは LP と同じく仮のもの。LP を変えたら合わせる
- 差し替えたら `npm run build:booklet` でPDFを作り直す

## 表現について

- マンガの中の変化（「前より静かな時間が増えてる」「最近、静かになったね」）は物語として控えめにし、14ページと裏表紙に「このマンガはフィクションです。いびきの変化には個人差があります」と入れています。受講者の実例のように見せる使い方（「実話」「受講者の声」などの表記）はしないでください
- 9ページ・15ページ・19ページで、無呼吸が疑われるサインがあれば医療機関へ相談するよう案内しています
- イラストは生成AIで作成しています（裏表紙に明記）

## 絵の作り方（作り直す・コマを足すとき）

- イラストは Higgsfield の画像生成（`gpt_image_2_5`、quality: high、1k）で作り、`img/` に縮小して保存しています。白黒のコマはグレースケールJPEG、表紙はカラー、ふくろう先生の小さな絵（`owl-*.png`）は背景透過PNG
- すべてのコマは、キャラクター表 `img/charsheet.jpg`（生成ジョブ `fc80fc7f-c2fa-47cb-afbd-edde42911ff0`）を参照画像にして描いています。プロンプトは [`prompts.json`](prompts.json)
- 画像には文字を入れず、セリフ・効果音・ラベルはすべて `pages.js` に文字として書いて重ねています。セリフの直しは `pages.js` だけで済みます
- コマの割り付けは `pages.js` の `rows`（行の高さの比と、右から順のコマ幅の比）、ふきだしの位置は `x` `y`（コマの中の0〜1）

## ファイル

```
booklet/
├── index.html          画面表示・PDF化の入口
├── booklet.css         紙面（A5）とふきだしのデザイン
├── pages.js            台本：コマ割り・セリフ・文字のページ
├── render.js           台本から20ページを組み立てる
├── prompts.json        絵の生成プロンプト
├── img/                コマの絵・表紙・登場人物・ふくろう先生
└── nemuri-kiroku.pdf   配布用PDF（npm run build:booklet で作成）
```

```bash
npm run build:booklet            # PDFを作る（Google Fonts を読み込むためネット接続が必要）
npm run build:booklet -- --png   # あわせて dist/booklet/ にページごとの確認用PNG
npm run build:bundle             # LPとあわせて、1ファイル版HTMLとPDFを dist/ibiki-bundle/ に作る
npm run test:e2e                 # ページ数・A5サイズ・絵の読み込み・ふきだしのはみ出し・文字のはみ出しを確認
```
