７日間のあと

むずかしいのは、始めることより続けること

小冊子の７日間で「静かな時間が増えた」と感じても、ひとりで続けていると、いつのまにか元のやり方に戻ってしまう方が少なくありません。

口やのどの筋肉のトレーニングや寝る姿勢の習慣は、数週間から数か月かけて身につけるものです。12週間コースは、その期間を一緒に走るためのコースです。

  • 自己流になっていても、気づけない

    体操は、舌の位置や口の開け方が少しずれるだけで、ねらった筋肉に効きにくくなります。

  • 記録をつけても、読み取り方がわからない

    いびきが大きい日と小さい日の差に、お酒・寝る姿勢・鼻づまりのどれが関わっているのか。記録を見比べないとわかりません。

  • ３週目あたりで、止まってしまう

    変化がゆるやかな時期に、やる気だけで続けるのは大変です。

12週間の内容

知る、鍛える、自分の習慣にする

1〜4週

知る・整える

  1. 録音と記録の始め方。自分のいびきが強くなる条件を知る
  2. 横向きで眠る習慣と、枕の高さの調整
  3. 舌の正しい位置と、口の体操の基本
  4. 鼻呼吸と寝室の環境。4週間の録音を比べる

5〜8週

鍛える・変える

  1. のどと舌のトレーニング（段階を上げる）
  2. お酒・夕食・入浴の時間を、記録に合わせて調整
  3. 首まわり・体重・日中の姿勢
  4. 自分に効く組み合わせを見つける。8週間の録音を比べる

9〜12週

定着させる

  1. 飲み会・旅行・疲れた日など、例外の日の過ごし方
  2. 家族と続ける仕組み（家族アカウント）
  3. あなた専用の「夜の10分ルーティン」を完成させる
  4. 卒業レポートと、これからの続け方

向いている方、向いていない方

向いている方

  • ７日間の記録で、自分のいびきの傾向が少し見えてきた方
  • 面談や通院の時間はとれないが、毎日５〜15分なら取り組める方

向いていない方

  • 寝ている間に呼吸が止まる、日中に耐えられないほど眠いなど、医療機関への相談が先の方

  • 記録や体操に取り組む時間が、しばらくとれない方
  • 動画とフォームだけでなく、直接会って話したい方

面談がなくても、本当に大丈夫ですか？

毎週、あなたの記録と体操の動画に、文字と短い動画でお返しします。わからないことはチャットでいつでも質問できます（平日は24時間以内に返信）。直接会って話したい方には向いていません。

スマホが苦手です。何歳でも受講できますか？

年齢の制限はありません。動画を見る、録音する、フォームで選ぶ、の３つができれば受講できます。最初の週に使い方の動画とチャットでのサポートがあります。

いびきが治ると約束してもらえますか？

お約束はできません。いびきの原因や変化には個人差があり、このコースは医療行為ではありません。そのかわり、はじめの14日間は理由を問わず全額をお返しします。

睡眠時無呼吸症候群の治療中です。

主治医の了承があれば受講できます。治療は主治医の指示どおりに続けてください。診断を受けていない方で、受講前チェックに当てはまる方は、先に医療機関でのご相談をお願いしています。

忙しくて取り組めない週があったら？

出張や体調不良などで取り組めない週は、チャットでお知らせください。最大４週間まで、お休みして期間を延ばせます。

自習版の「静寂の夜メソッド」との違いは？

自習版は、動画と教材で自分のペースで取り組むものです。12週間コースは、毎週の個別フィードバック、体操の動画添削、チャットでの質問がつきます。
