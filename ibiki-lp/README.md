# いびき改善プログラム LP「静寂の夜メソッド」（仮称）

自宅でできるいびき改善のオンライン講座を売るための、広告用ランディングページです。
ターゲット像（20〜80代・中心は40〜70代、いびきに悩む本人と、隣で眠るパートナー）とタイトルコンセプト10パターンをもとに作っています。

無料小冊子（マンガ「私の眠りの記録」A5・20ページ）は [`booklet/`](booklet/) にあります（[PDF](booklet/nemuri-kiroku.pdf)・[説明](booklet/README.md)）。

小冊子を入口に、面談・通話なしのオンラインだけで30万円の「12週間 個別フィードバックコース」（仮の商品案）を販売する流れも入っています。全体の設計（流れ・LINE配信の全文・動画セミナーの台本・運用・収支シミュレーター・法令のチェック・公開までにやること）は [`funnel/index.html`](funnel/index.html) にまとめています。

講師ドクターKが話す約15分の動画（いびき改善 5ステップ・字幕入り・YouTube／Vimeo用）は [`../video/`](../video/README.md) で作ります（`npm run build:video`）。

```
広告 → 小冊子プレゼント（free/）→ LINE 7日間の記録チャレンジ → 無料動画セミナー（40分）
     → 12週間コース（program/）の申込フォーム → 受講可否をLINEで連絡 → 決済 → 受講開始
     申し込まなかった方 → 自習版（このLP） ／ 受診の目安に当てはまった方 → 医療機関を案内（販売の案内は送らない）
```

ビルド不要の静的ファイルです（外部ライブラリなし。フォントのみ Google Fonts）。**このフォルダをそのままサーバーにアップロードすれば動きます。**

## ページの構成

| 順 | セクション | ねらい |
|---|---|---|
| 1 | ファーストビュー（夜） | 見出し（広告キーワード別に出し分け）＋「今夜から始める」ボタン＋一晩のいびき録音グラフ（いびきの夜／静かな夜の切り替え） |
| 2 | セルフチェック | ターゲットの悩み8項目をタップで確認。**無呼吸を疑うサインに当てはまると、先に医療機関を案内** |
| 3 | いびきが起こるしくみ | 「体質ではない」根拠として、寝姿勢・筋肉のゆるみ・口呼吸・夜の習慣の4つを説明 |
| 4 | グッズ・医療との比較 | 「グッズもサプリも効かなかった」人へ。グッズ／本プログラム／医療機関の役割の違い |
| 5 | 3つの習慣 | メソッドの柱（寝姿勢・のどと舌のトレーニング・鼻呼吸と夜の習慣） |
| 6 | 最初の7日間 | 1日目に録音 → 毎日1つずつ → 7日目に録音して聞き比べ |
| 7 | 隣で眠るご家族へ | パートナー向けの訴求。音の大きさの目安（dB）と、すすめ方のコツ |
| 8 | 受講者の声 | **掲載例。実際の声に差し替えが必要** |
| 9 | 講師 | **要入力** |
| 10 | 受講内容と料金 | 決済ページへのボタン、返金保証（要確認） |
| 11 | よくあるご質問 | 年齢・いびき歴・所要時間・無呼吸症候群・家族の申し込み・スマホ・器具 |
| 12 | 受診の目安 | 医療機関に相談すべきサイン |
| 13 | 締め（夜明け） | 「隣で眠る人に『静かになったね』と言われる日は、意外と近い。」 |

40〜70代が中心のため、本文は17px・行間広め、ボタンは高さ52〜64px、ヘッダーに「文字を大きく」ボタン（設定はブラウザに保存）を付けています。スマホでは画面下に追従ボタンが出ます。

## 公開前に必要なこと

HTML・JS 内の `【要確認】` `【要設定】` `【要差し替え】` `【要記入】` コメントと、画面上の点線枠（`掲載例` など）がすべて対象です。`grep -rn "【要" ibiki-lp/` で一覧できます。

1. **プログラム名**：「静寂の夜メソッド」は仮称（タイトルコンセプト2より）。変更する場合は `grep -rn "静寂の夜メソッド" ibiki-lp/` で一括置換
2. **講座の仕様**：「1日10分」「最初の7日間の内容」「動画の本数」「質問サポート」「スマホで受講」を実際の講座に合わせる
3. **料金・返金保証**：`〇〇,〇〇〇円` を税込価格に。返金保証を設けない場合は `.guarantee` の段落と FAQ・特商法表記の該当部分を削除
4. **受講者の声**：実在の受講者の声（本人の掲載許諾つき）に差し替え、`掲載例` の表示（`.todo-note` `.todo-tag`）を削除。用意できるまではセクション `#voices` に `hidden` を付けて非表示に
5. **講師・監修者**：氏名・資格・経歴・写真を入れ、`.todo-note` を削除
6. **決済ページ**：`assets/js/main.js` の `CONFIG.checkoutUrl` に決済ページ（申込フォーム）のURLを設定
   - 広告の流入元（`utm_*` `gclid` など）と、表示した見出しパターン（`lp_variant`）を決済ページのURLに付けて引き継ぎます
   - 未設定のときはボタンが料金欄を指したままになり、手元の確認（localhost・ファイルを直接開いたとき）では「未設定です」と表示します
7. **特定商取引法に基づく表記**：`tokushoho.html` の各項目を記入
8. **運営者名**：フッターの `運営：〇〇〇〇`
9. **ファーストビューの写真**：`assets/img/hero-night.jpg`（PC用 1600×1075）と `hero-night-sm.jpg`（スマホ用 960×645）は、生成AI（Higgsfield）で作ったイメージ写真です。実在の受講者ではないため「※写真はイメージです」と表示しています。撮影した写真や素材写真に替える場合は、同じファイル名・同じ縦横比（3:2）で差し替えてください（人物は右寄り、左側を暗めに空けると見出しが読みやすくなります）
10. **OGP**：`index.html` の `og:url` を公開URLに。SNS・LINEで共有する場合は `og:image`（1200×630）も追加
11. **計測**：Google タグマネージャーを入れる場合は `<head>` に追加。ボタンのクリックは `dataLayer` に `cta_click`（`cta`＝header/hero/sticky/offer/closing、`lp_variant`）として送っています

### 12週間コースの販売導線（free/・program/）

設計書 `funnel/index.html` の「8. 公開までにやること」が一覧です。コードで設定する箇所は次のとおりです。

- **LINEの友だち追加URL**：`assets/js/funnel.js` の `CONFIG.lineUrl`（未設定のときは手元の確認で「未設定です」と表示）
- **申込フォームの送信先**：`CONFIG.applyEndpoint`（Googleフォーム・スプレッドシートのWebアプリなど、`application/x-www-form-urlencoded` のPOSTを受けられるURL）。流入元（`utm_*` など）と入力にかかった秒数（`elapsed`）も一緒に送ります。未設定の公開サーバーでは送信ボタンを止め、「準備しています」と表示します
- **受講前チェック**：無呼吸・日中の強い眠気・朝の頭痛のどれかに「はい」の方は送信できず、医療機関を案内します（`RED_FLAGS`）。治療中（CPAPなど）の方は「主治医に確認した」が必須
- **ページの設定を上書きする**：各ページで `funnel.js` より前に `window.LP_CONFIG = { lineUrl: '…', applyEndpoint: '…' }` を置いても設定できます
- **商品の中身・価格・定員・担当スタッフ・フィードバック例**は仮です（`【要確認】` と点線枠）。決まったら `program/index.html` と `tokushoho.html#course` を合わせて直してください
- `funnel/` は社内資料なので、公開サーバーには置かないでください（`noindex` 付き）

## 表現について（公開前に必ず確認）

健康にかかわる通信販売の広告は、**景品表示法**（優良誤認）と**特定商取引法**（誇大広告の禁止 第12条）の対象です。効果をうたう表現には、裏づけとなる合理的な根拠（受講者の実データなど）が求められます。

| パターン・箇所 | 注意点 | 言い換えの例 |
|---|---|---|
| 1.「たった1週間で家族が驚いた」 | 期間と効果の断定。根拠がなければ優良誤認のおそれ | 「最初の1週間で、3つの習慣を身につける」 |
| 2.「病院に行かずに、いびきが止まった」 | 効果の断定に加え、睡眠時無呼吸症候群の人の受診を遠ざけるおそれ。「睡眠専門家」は資格・所属の根拠が必要 | 「通院の前に、自宅で見直せること」 |
| 5.「最後の処方箋」 | 「処方箋」は医療を連想させる言葉。医療行為ではない講座には避けたほうが安全 | 「いびき改善、最後の選択肢」 |
| 9.「血圧も体重も…すべて変わる」 | 病気の改善を思わせる健康効果の表現。根拠が必要 | 「睡眠が変われば、朝の目覚めと日中の集中力が変わる」 |
| 受講者の声 | 架空の体験談は使えません。「効果には個人差があります」と添えても、一般的な結果と大きく違う体験談は優良誤認とみなされるおそれがあります（消費者庁「打消し表示に関する表示方法及び表示内容に関する留意点」） | 実際の声を、結果の出なかった人の割合とあわせて掲載 |
| 決済ページ | 申込みの最終確認画面に、価格・支払時期・提供時期・申込みの撤回（返金）の条件などを表示する義務があります（特定商取引法 第12条の6） | 決済サービス側の確認画面を確認 |

1・2・9 は検索語句から自動で選ばないようにしてあります（`?v=` で明示したときだけ表示）。

LPの本文では、医療との線引きをはっきりさせています（比較表で医療機関の治療を「無呼吸の疑いがある方に」と位置づけ、セルフチェック・FAQ・受診の目安・フッターで医療機関への相談を案内）。いびきの陰に睡眠時無呼吸症候群が隠れていることがあるためで、信頼につながる要素でもあるので残すことをおすすめします。

## 開発者向け

```bash
npm install            # 初回のみ
npm run serve:ibiki    # http://localhost:8000/ で確認
npm run build:bundle   # 共有用に dist/ibiki-bundle/ へ、LP・小冊子・小冊子プレゼント・12週間コース・設計書の1ファイル版HTMLとPDFを作る
npm test               # HTML検証 + 自動テスト（このLPは tests/ibiki.e2e.test.js、販売導線は tests/funnel.test.js）
```

自動テストの内容：375×667 の画面で申し込みボタンが最初に見える／確認用の見出し切り替え／幅320・360・768・1280pxで全10パターンとも横スクロールなし／見出しの出し分け／一晩の記録の切り替え／セルフチェックと医療機関の案内／決済URLへの流入元の引き継ぎ／追従ボタン／文字サイズの保存／アクセシビリティ（axe、ライト・ダーク）

販売導線のテスト：小冊子プレゼントの最初の画面にLINEボタン／LINEのURL設定／幅320・390・1280pxで横スクロールなし／受診の目安に当てはまると送信できない／治療中の方の確認と送信内容（流入元つき）／送信先が未設定のときの動作／収支シミュレーターの計算／アクセシビリティ（axe）
