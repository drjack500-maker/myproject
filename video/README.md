# YouTube動画「いびき改善 5ステップ」（約15分）

現役歯科医師ドクターKが、いびきの原因と今日からできる改善法を5つのステップで話す動画です。
LPの動画（Vimeoの埋め込み）にも、YouTube にもそのまま使えます。

```bash
npm run build:video   # → dist/video/
```

| できあがるファイル | 内容 |
|---|---|
| `いびき改善5ステップ_ドクターK.mp4` | 1920×1080・30fps・字幕入り（約14分30秒） |
| `captions.ja.srt` | 字幕ファイル（YouTube・Vimeo の字幕として登録できる） |
| `thumbnail.jpg` | サムネイル（1280×720） |
| `youtube.txt` | タイトル案・概要欄（チャプター入り）・タグ。LPで公式LINEのボタンを出す時刻の目安も書いてある |
| `timeline.json` | 場面と字幕の時刻（確認用） |

## ファイル

```
video/
├── scenes.js       台本（ナレーション＝字幕）と画面の指定。41場面
├── readings.js     読み上げの読み（字幕はそのまま、音声だけ読みを直す）
├── narration.json  ナレーション音声（Higgsfield で生成した wav のURLと job ID）
├── align.json      字幕の切れ目（各場面の音声の何秒で次の行に切り替えるか）
├── slide.html      スライドの見た目（1920×1080）
├── slide.js        場面ごとの描き分け
├── diagrams.js     図（気道の断面図・ホース・枕・録音の波形・のどちんこ・口の形 など）
└── img/            この動画のために描いた絵（冒頭・鼻づまり・舌の突き出し・舌回し）
tools/build-video.js
tools/align-narration.py   字幕の切れ目を音声認識で合わせて align.json を作る
```

- 絵は小冊子「私の眠りの記録」と同じ夫婦（誠さん・由美子さん）です。小冊子の絵（`ibiki-lp/booklet/img/`）も使っています
- ナレーションは Higgsfield に登録された声（表示名「尾崎裕院長」＝尾崎隆理事長の声）で合成しました。音声認識で全場面の読みを確かめ、読み違えた3場面（「気道」「体質」「睡眠時無呼吸症候群」）は読みを直して作り直しています
- 字幕の切り替えは、音声認識（Whisper）で台本の各行が話し始められる位置を探し、その直前の間に合わせています（`align.json`）。声が文と文を続けて読んだところも、言葉の位置で切り替わります

## 直すとき

- **台本を直す**：`scenes.js` の該当場面を直し、その場面だけ Higgsfield（seed_audio・同じ声）で音声を作り直して、`narration.json` の URL を差し替える。`dist/video-cache/` の同じ名前の wav を消してから `npm run build:video`。続けて `python3 tools/align-narration.py s05`（場面ID）で字幕の切れ目を合わせ直し、もう一度 `npm run build:video`（`pip install faster-whisper pykakasi` が必要。align.json にない場面は無音の位置で合わせます）
- **読み違い**：`readings.js` に「字幕の表記 → 読み」を足して、その場面を作り直す
- **見た目**：`slide.html` / `slide.js` / `diagrams.js` を直して `npm run build:video`（音声はそのまま）

## 公開前に確認すること

- **講師プロフィール**（場面2の画面）：「歯科医師歴20年以上」「3,000名以上の患者をサポート」「テレビ・健康雑誌への出演・監修多数」「寝室から夫婦喧嘩をなくす歯科医師」は、いただいた文面のままです。事実と、根拠（資料）があることを確認してください。歯科医院の集患につながる場合は医療広告ガイドラインの対象になり、患者数などの実績や体験談の表示には制限があります
- **合成音声であること**：概要欄に「ナレーションは合成音声です」と入れています。尾崎隆理事長ご本人の了承のうえで公開してください
- **効果の表現**：「改善」「深い眠りを手に入れる」は効果を保証しない言い方にとどめ、「効果には個人差があります」を画面と概要欄に入れています
- **トレーニングの実演**：画面はイラストです。ドクターKご本人の実演映像があれば、ステップ3（5:51〜9:14）に差し込むと説得力が増します
- **公式LINEのURL**：`youtube.txt` の【要設定】に入れる
