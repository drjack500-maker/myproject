# SNORE RESET 56｜無料56秒スターター動画

LP（`snore_reset_56_sales_lp_v3_with_people.html`）の「無料56秒スターター動画」本体です。
寝る前に座ったまま、画面を見ながら一緒にできる56秒のセルフケア動画です。

| ファイル | 内容 |
|---|---|
| [`output/snore-reset-56-starter.mp4`](output/snore-reset-56-starter.mp4) | **完成動画**（56.0秒・縦型 1080×1920・30fps・H.264＋AAC） |
| [`output/poster.jpg`](output/poster.jpg) | サムネイル（LPの `<video poster>` やメールの画像に使う） |
| [`captions.srt`](captions.srt) | 日本語字幕（YouTube などにアップロードするとき用）。ナレーション原稿としても使える |
| `scene.html` | 動画の画面（ブラウザで開くとその場で再生プレビューできる） |
| `audio.py` | BGM と合図の音を合成するスクリプト（外部素材なし） |
| `render.js` | `scene.html` を1コマずつ撮影して MP4 に書き出すスクリプト |

## 構成（56秒）

| 時間 | 場面 | 画面の内容 | 音 |
|---|---|---|---|
| 0:00–0:05 | オープニング | 「今夜、まず56秒。」／舌とのどの3ステップ／歯みがきのあと・座ったままでOK | ベル |
| 0:05–0:10 | 準備 | 背すじを伸ばす・肩の力を抜く・口を閉じて鼻呼吸。断面図に鼻からの空気の流れ | 吸う／吐く息の音 |
| 0:10–0:24 | STEP 1 舌スライド | 舌先を「スポット」（上の前歯のすぐ裏）に当て、上あごをなぞって奥へ。約2秒×5回 | 1回ごとにベル |
| 0:24–0:38 | STEP 2 舌の吸いつけ | 舌全体を上あごにピタッと押し当てて5秒キープ×2回（カウントダウン表示） | 開始・終了のベル、毎秒の小さなカウント音 |
| 0:38–0:50 | STEP 3「アー」発声 | 口を大きく開けて「アー」。のどの奥（軟口蓋）が上がる様子を図で表示。×3回 | 1回ごとにベル |
| 0:50–0:56 | エンディング | 「56秒、完了！」→ 56日プログラムへの案内 → 注意書き | 完了のアルペジオ |

- 右上のリングは動画の残り秒数（56→）。進行バーで今どのステップかが分かります。
- 本編中は画面下に「痛みや違和感があれば、すぐに中止してください。」を常に表示しています。
- ナレーションは入れていません（音を出さずに見る人が多いため、指示はすべて画面の文字と図で分かるようにしています）。声を入れる場合は `captions.srt` がそのまま読み上げ原稿になります。

### 内容の根拠と表現の注意

- 3つの動きは、LPで引用している2015年のランダム化試験（[PubMed 25950418](https://pubmed.ncbi.nlm.nih.gov/25950418/)）で使われた口腔咽頭エクササイズのうち、自宅で道具なしに始めやすいもの（舌先で上あごをなぞる／舌全体を上あごに吸いつける／「アー」で軟口蓋を上げる）を選んでいます。
- 回数・秒数は56秒に収めるための**スターター用の短縮版**です。研究と同じ量ではないため、LPと同じく「56秒で改善する」とは言っていません。エンディングで「効果を保証するものではありません」「呼吸が止まる・強い日中の眠気などがある場合は医療機関へ」と表示しています。
- 公開前に、監修者（医師・歯科医師など）がいる場合は動きの説明と注意書きを確認してもらってください。

## LP・メールでの使い方

LP の登録完了後のページやメールから、動画ファイル（または YouTube の限定公開URL）へ誘導します。ページに直接埋め込む場合の例:

```html
<video src="snore-reset-56-starter.mp4" poster="poster.jpg"
       controls playsinline preload="metadata"
       style="width:100%;max-width:360px;border-radius:24px"></video>
```

## 作り直すとき

文言・タイミング・色は `scene.html`、音は `audio.py` を編集してから書き出します（Node.js・Python 3＋NumPy・ffmpeg・Playwright の Chromium が必要。フォントは Google Fonts の Noto Sans JP / Inter を読み込むのでネット接続が必要）。

```bash
cd snore-reset-56/starter-video
node render.js --stills 3,15,45   # 指定した秒の静止画で確認（output/still-*.png）
node render.js                    # output/snore-reset-56-starter.mp4 と poster.jpg を書き出す（数分かかる）
```

- `scene.html` をブラウザで直接開くと再生プレビュー、`scene.html?t=15` でその秒の静止画になります。
- タイミングを変えたときは、`audio.py` の効果音の時刻も合わせて変えてください（`PHASES` / `S1_REP` / `S2_HOLDS` / `S3_REP` と対応）。
- 横型（16:9）や正方形が必要な場合は `scene.html` のレイアウトを別に作ります。
