# SNORE RESET 56｜無料56秒スターター動画

LP（`snore_reset_56_sales_lp_v3_with_people.html`）の「無料56秒スターター動画」本体です。
寝る前に座ったまま、画面を見ながら・ナレーションを聞きながら一緒にできる56秒のセルフケア動画です。

| ファイル | 内容 |
|---|---|
| [`output/snore-reset-56-starter.mp4`](output/snore-reset-56-starter.mp4) | **完成動画**（56.0秒・縦型 1080×1920・30fps・H.264＋AAC・ナレーション入り） |
| [`output/poster.jpg`](output/poster.jpg) | サムネイル（LPの `<video poster>` やメールの画像に使う） |
| [`output/captions.srt`](output/captions.srt) | ナレーションの日本語字幕（YouTube などにアップロードするとき用） |
| `timeline.js` | **タイミングとナレーション原稿**（画面と音の両方がこのファイルを読む） |
| `narration/` | ナレーション音声（1行ずつ） |
| `scene.html` | 動画の画面（ブラウザで開くとその場で再生プレビューできる。音は出ない） |
| `audio.py` | BGM・合図の音を合成し、ナレーションと合わせるスクリプト |
| `render.js` | `scene.html` を1コマずつ撮影して MP4 に書き出すスクリプト |

## 構成とナレーション（56秒）

| 時間 | 場面 | 画面 | ナレーション |
|---|---|---|---|
| 0:00 | オープニング | 「今夜、まず56秒。」／歯みがきのあと・座ったままでOK | 今夜、まず56秒。いっしょに始めましょう。 |
| 0:04.6 | 準備 | 姿勢と鼻呼吸。断面図に鼻からの空気の流れ | 背すじを伸ばして、鼻から吸って…／ゆっくり、吐いて… |
| 0:09.9 | STEP 1 舌スライド | 舌先を「スポット」（上の前歯のすぐ裏）に当て、上あごをなぞって奥へ。約2秒×5回 | 舌先を、前歯のすぐ裏へ。／上あごを、なぞって奥へ。／2回目。3回目。4回目。ラスト。 |
| 0:23.7 | STEP 2 舌の吸いつけ | 舌全体を上あごに押し当てて5秒キープ×2回（カウントダウン） | 舌全体を、上あごにピタッ。／あと2秒。／ゆるめて。／もう一度、ピタッ。／あと2秒。／ゆるめて。 |
| 0:38.6 | STEP 3「アー」発声 | 口を開けて「アー」。のどの奥（軟口蓋）が上がる様子を図で表示。×3回 | 口を大きく開けて、アー。／のどの奥を、上げるように。／もう一回、アー。／ラスト、アー。 |
| 0:50.5 | エンディング | 「56秒、完了！」→ 56日プログラムへの案内 → 注意書き | おつかれさまでした。／明日の夜も、同じ56秒を。 |

- 「ピタッ」「アー」の声と、画面のキープ開始・口が開くタイミングが重なるように合わせてあります。
- 右上のリングは動画の残り秒数（56→）。進行バーで今どのステップかが分かります。
- 本編中は画面下に「痛みや違和感があれば、すぐに中止してください。」を常に表示しています。
- 声が出ている間は BGM と合図の音が自動で下がります。全体の音量は約 -16 LUFS（スマホ・Web向けの一般的な大きさ）です。

### ナレーション音声について

- Higgsfield の音声生成（ElevenLabs v4・プリセット音声「Maya」）で1行ずつ作りました。読み間違いを防ぐため、一部はかなで読ませています（`timeline.js` の `say` が読ませた文、`text` が字幕に出す文）。
- 生成した音声は音声認識（Whisper）で読み上げ内容を確認済みです。
- 商用利用の条件は、Higgsfield の利用規約・ご契約プランでご確認ください。

### 内容の根拠と表現の注意

- 3つの動きは、LPで引用している2015年のランダム化試験（[PubMed 25950418](https://pubmed.ncbi.nlm.nih.gov/25950418/)）で使われた口腔咽頭エクササイズのうち、自宅で道具なしに始めやすいもの（舌先で上あごをなぞる／舌全体を上あごに吸いつける／「アー」で軟口蓋を上げる）を選んでいます。
- 回数・秒数は56秒に収めるための**スターター用の短縮版**です。研究と同じ量ではないため、LPと同じく「56秒で改善する」とは言っていません。エンディングで「効果を保証するものではありません」「呼吸が止まる・強い日中の眠気などがある場合は医療機関へ」と表示しています。
- 公開前に、監修者（医師・歯科医師など）がいる場合は動きの説明と注意書きを確認してもらってください。

## 作り直すとき

Node.js・Python 3＋NumPy・ffmpeg・Playwright の Chromium が必要です（フォントは Google Fonts の Noto Sans JP / Inter を読み込むのでネット接続が必要）。

```bash
cd snore-reset-56/starter-video
node render.js --stills 3,15,45   # 指定した秒の静止画で確認（output/still-*.png）
node render.js                    # output/ に動画・サムネイル・字幕を書き出す（数分かかる）
```

- **文言・色・図**は `scene.html`、**タイミングとナレーション**は `timeline.js`、**BGM・合図の音**は `audio.py` を編集します。
- ナレーションを差し替えるときは、新しい音声を `narration/` に置き、`timeline.js` の `narration` の `file`・`at`（声が出始める秒）・`text` を直します。前後の無音は自動で切り、音量もそろえます。ナレーション同士が重なると `audio.py` がエラーで止まって知らせます。
- `scene.html` をブラウザで直接開くと再生プレビュー（音なし）、`scene.html?t=15` でその秒の静止画になります。
- 横型（16:9）や正方形が必要な場合は `scene.html` のレイアウトを別に作ります。
